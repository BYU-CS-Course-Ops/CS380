# Persona Template — for honest, evidence-based proxies

*Use this when you can't (yet) reach a real user for a given need. A persona here is **not** an invented character — it's a summary of what you actually found, with every claim tagged as **evidence** or **assumption.***

---

## Rules for an *honest* persona

1. **Tag every claim:** `[E]` = evidence (with a source) · `[A]` = assumption (a labeled guess you'd want to verify).
2. **No invented facts.** If you don't know it, mark it `[A]` — don't dress a guess up as fact.
3. **Cite your sources.** Forum threads, reviews, articles, community posts, your own observation — name or link them.
4. **Say what you'd verify.** List the top assumptions you'd test in a real conversation.
