### Goal

The theater runs Prop Loft itself, on its own server, through a real production, with no developer on call.

### Context

Design §2, goal 4; design §8, milestone 5 (deploy, seed 60 items, the strike-night trial). On the [roadmap](https://github.com/prop-loft/prop-loft/blob/main/docs/roadmap.md) after the MVP milestones, except the setup guide (#{{SETUP}}), which contributors need now.

### Acceptance criteria

- [ ] A newcomer can set Prop Loft up from the docs alone.
- [ ] It's deployed on the theater's server with the 60-item costume stock loaded.
- [ ] A strike night runs on it, and what went wrong is filed as issues.
- [ ] Every sub-issue is closed.
